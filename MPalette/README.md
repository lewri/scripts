# TH MPalette Data

Extracted palette file used in MPalette.dat of Theme Hospital. In CorsixTH, this is used in [aux_ui](https://github.com/CorsixTH/CorsixTH/blob/master/CorsixTH/Bitmap/aux_ui.spec); and any other sprite sheets without palette data.

`MPalette.pal` - Raw .pal file, use with applications like [Usenti](https://www.coranac.com/projects/usenti/) to apply it to your BMP image\
`MPalette.png` - Visual grid of colours in MPalette\
`MPalette.txt` - RGB values of each colour entry in the MPalette\

You can use this data to make sure any additional graphics to [aux_ui](https://github.com/CorsixTH/CorsixTH/blob/master/CorsixTH/Bitmap/aux_ui.spec) will be represented appropriately.
